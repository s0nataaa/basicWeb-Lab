# Basic Web Programming - UMN

This repository contains a collection of assignments, lab sessions, and exercises from the various modules of the **Basic Web Programming** course at **Universitas Multimedia Nusantara (UMN)**.

## 📌 About This Repository
This repository is created to document the learning process of web development, ranging from HTML fundamentals and document structures to styling with CSS and implementing modern layouts using Flexbox and other web page structures.

## 📂 Module Structure
Each folder in this repository is organized by weekly course modules:
- **Week 1-3:** Introduction to HTML basics, document structure, CSS styling, and basic layout creation.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- Bootsrap
- Javascript
